# mp-cool-lex-java

The Cool-lex order for multiset permutations, along with an associated algorithm, was invented by Aaron Williams
(<https://www.researchgate.net/profile/Aaron-Williams>).

The [publication](https://epubs.siam.org/doi/pdf/10.1137/1.9781611973068.107) is copyrighted
by [SIAM (Society for Industrial and Applied Mathematics)](https://siam.org).

You may need to obtain the respective permissions to use Cool-lex
from both the author and SIAM, as governed by applicable laws and academic practices.

The code in this repository is authored by the mp-cool-lex-java [contributors](CONTRIBUTORS), and is licensed under Apache License, version 2.0 license.
